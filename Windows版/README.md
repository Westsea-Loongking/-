# 意志图谱 / Will Map · Windows版

> 从你反复作出的选择中，寻找正在保护的东西。

意志图谱是一个开源、可自托管的叙事型自我探索工具。

它通过结构化问题、价值冲突情境、矛盾分析和用户校正，
帮助用户提出并持续修订一套关于自己的解释：

- 我反复保护什么？
- 什么情境最容易触发我的防御？
- 我通常采用什么策略？
- 我的行为是否背离了自己认可的价值？
- 当两个重要价值发生冲突时，我愿意承担什么代价？
- 当我偏离自己的原则后，如何重新校正？

项目将这种相对稳定、但可以被检验和修改的行动逻辑称为：

**“意志图谱”**

这里的“意志”不是固定人格类型，也不是隐藏在人体内、等待系统发现的
“真实本质”。它是一组根据当前回答形成的叙事假设，用户可以查看依据、
提出反例、修改措辞，并通过现实事件继续验证。


## 目录结构

```
Windows版/
├─ will_analyzer/
│  ├─ main.py          # 入口
│  ├─ app.py           # 图形界面
│  ├─ data/            # 题库 + 维度内容库
│  └─ engine/          # 评分 + 意志生成
└─ WillMap.spec        # PyInstaller 打包配置
```

## 运行

需要 Python 3.x，在「Windows版」目录下运行：

```bash
python will_analyzer/main.py
```

## 打包成 exe

安装 PyInstaller 后：

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean WillMap.spec
```

生成的可执行文件在 `dist/意志图谱.exe`。

## 键盘操作（答题页）

- `1`–`5`：日常倾向题选择对应选项（含小键盘）
- `A` / `B`：价值冲突题选择对应选项（大小写均可）
- `←` / `↑`：上一题（含小键盘）
- `→` / `↓`：下一题（含小键盘）

## 说明

导出的报告会自动保存到桌面。本程序输出的是可解释、可修订的自我叙事模型，不是医学诊断。
